# Bin It

Lap times, leaderboards and challenges for a shared sim-racing rig, so everyone knows just how
many times they binned it. Everything stays on the PC: no accounts, no cloud.

## Download

* **[Installer](https://github.com/Masstrix/BinIt/releases/latest/download/BinIt-setup.exe)**: adds
  Bin It to the Start menu and updates itself every time it starts.
* **[Portable exe](https://github.com/Masstrix/BinIt/releases/latest/download/BinIt-portable.exe)**:
  no install, run it from anywhere. It doesn't update itself.

Windows 10/11 with the WebView2 runtime. The app isn't code-signed, so SmartScreen may ask once
("More info", "Run anyway"). What changed in each version: [releases](https://github.com/Masstrix/BinIt/releases).
